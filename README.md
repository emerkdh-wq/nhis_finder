# ♿ 장애인 건강검진기관 위치찾기

보건복지부가 지정한 **장애인 건강검진기관** 목록에서 지역과 검진 종류로 기관을 찾아주는 웹 페이지입니다.

## 기능

- **엑셀 자료 기반 목록:** `data/institutions.csv`에 있는 장애인 건강검진기관 43곳만 보여줍니다.
- **필터:** 시·도와 시·군·구로 고를 수 있고, 기관명이나 주소로 검색할 수 있습니다. 목록에는 지역별 기관 수가 함께 표시됩니다.
- **검진 종류 필터:** 일반, 구강, 위암, 대장암, 간암, 유방암, 자궁경부암, 폐암 중에서 고르면, 선택한 검진을 모두 받을 수 있는 기관만 남습니다.
- **기관 카드:** 주소, 우편번호, 검진 가능 항목을 보여줍니다. 미실시 항목은 취소선으로 표시됩니다. 네이버 지도·카카오맵으로 바로 열 수 있고 주소를 복사할 수 있습니다.
- **예약 전 확인 목록:** 휠체어, 수어통역 등 전화로 물어볼 항목을 체크할 수 있습니다.

## 자료 업데이트

`data/institutions.csv`를 고친 뒤 `index.html` 안의 `DATA` 배열도 같은 내용으로 바꿔야 합니다.

## 사용법

`index.html`을 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages**에서 Source를 `main` 브랜치의 `/ (root)`로 지정하세요.

## 주의

- 목록은 제공된 엑셀 자료 기준입니다. 운영 여부와 검진 가능 항목은 방문 전에 기관에 확인하세요.
