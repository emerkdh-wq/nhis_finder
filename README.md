# 🏥 건강보험 검진기관 위치찾기

지역과 검진 종류를 고르면 네이버 지도, 카카오맵, 구글 지도에서 가까운 국가건강검진 기관을 바로 찾아주는 웹 페이지입니다.

## 기능

- **지역 선택:** 17개 시·도와 시·군·구, 읍·면·동이나 역 이름으로 고를 수 있습니다. 지역을 비워두면 휴대폰 지도 앱이 현재 위치 주변으로 검색합니다.
- **검진 종류:** 일반검진, 위·대장·간·유방·자궁경부·폐 암검진, 구강검진, 영유아검진 중에서 고를 수 있고, 각 검진의 대상 나이와 주기 안내가 함께 나옵니다.
- **요일 필터:** 토요일, 일요일, 공휴일, 야간 검진을 검색어에 넣을 수 있습니다.
- **추가 키워드:** '수면내시경', '여성전용', 병원 이름 같은 말을 더해 검색을 좁힐 수 있습니다.
- **지도 바로가기:** 버튼 하나로 네이버 지도, 카카오맵, 구글 지도, 네이버 검색, 국민건강보험공단 홈페이지를 엽니다.
- **최근 검색:** 최근 검색 5개를 브라우저에 저장합니다.

## 사용법

`index.html`을 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages**에서 Source를 `main` 브랜치의 `/ (root)`로 지정하세요. 그러면 `https://<사용자명>.github.io/nhis_finder/` 주소로 열 수 있습니다.

## 주의

- 지도 검색 결과는 각 지도 서비스의 정보입니다. **국가건강검진 지정기관인지는 예약 전에 꼭 확인하세요.**
- 공식 지정기관 목록은 [국민건강보험공단](https://www.nhis.or.kr) 홈페이지나 'The건강보험' 앱의 검진기관 찾기에서 볼 수 있습니다.
- 공단 고객센터: 1577-1000
- 검진 대상과 주기는 해마다 바뀔 수 있습니다. 공단의 대상조회로 확인하세요.
