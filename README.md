# ♿ 장애인 건강검진기관 위치찾기

보건복지부가 지정한 **장애인 건강검진기관**을 지역별로 찾아주는 웹 페이지입니다. 이런 검진기관은 휠체어로 이용할 수 있는 시설과 장비, 수어통역 같은 의사소통 지원을 갖추고 있습니다. 지역을 고르면 네이버 지도, 카카오맵, 구글 지도에서 바로 검색됩니다.

## 기능

- **지역 선택:** 17개 시·도와 시·군·구 중에서 고를 수 있습니다. 시·도를 비워두면 휴대폰 지도 앱이 현재 위치 주변으로 검색합니다.
- **넓혀 찾기:** 장애인 건강검진기관은 아직 수가 적습니다. 시·군·구로 찾았는데 결과가 없으면 버튼 하나로 시·도 전체로 넓혀 다시 검색할 수 있습니다.
- **예약 전 확인 목록:** 휠체어 이동, 수어통역, 발달장애인 안내, 보호자 동행 등 전화로 물어볼 항목을 체크해 둘 수 있고, 체크한 내용은 브라우저에 저장됩니다.
- **최근 검색:** 최근 검색 5개를 브라우저에 저장합니다.
- **접근성:** 큰 글씨와 큰 버튼을 쓰고, 키보드 포커스가 잘 보이며, 화면낭독기 안내를 지원합니다.

## 사용법

`index.html`을 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages**에서 Source를 `main` 브랜치의 `/ (root)`로 지정하세요.
